# M0 implementation note

> Trạng thái: đang triển khai; chưa đạt DoD cho tới khi có firmware/board evidence
> và người dùng xác nhận nghe được speaker.

## Scope

Vertical slice tối thiểu là PTT → Opus → direct WebSocket v3 → VAD/ASR → Groq
stream → VieNeu stream → Opus → speaker. Các service control-plane vẫn được
khởi động và health-check trong cùng runtime harness nhưng không nằm trong critical
audio path.

## Config and safety

- Config đọc từ environment/manifest fixture; không hard-code model, provider,
  endpoint, credential, personality, prompt hoặc GPIO.
- `secrets/groq.keys` chỉ dùng cho test harness; production chỉ một secretRef.
- Chưa flash firmware khi board profile/pin map chưa được xác minh.
- Không đổi kết nối mạng máy tính; Tailscale chỉ dùng `serve` private sau khi user
  cài/enable.

## Evidence — host/config gate

Đã chạy trên Ubuntu host (không đổi interface/Wi-Fi):

- `veetee-server/.venv/bin/pytest -q`: **7 passed** (golden v1/v2/v3 framing,
  pipeline fixture, WebSocket v3 handshake/turn).
- `npm run build` và `npm test` trong `veetee-manager-api`: **2 tests passed**;
  `npm run typecheck`, lint, unit test và build của Manager Web: **12 unit tests
  passed**.
- `python3 -m pytest -q tools/runtime`: **3 passed** (dependency order, cycle và
  shell operator rejection).
- Host-native supervisor manifest đã start + readiness-check đồng thời:
  `veetee-manager-api` (HTTP 18001), `veetee-server` (HTTP/WS 18000) và
  `manager-web-preview` (HTTP 18081). Các port này là override trong manifest để
  không đụng service đang chạy ở port mặc định của workspace khác.
- API runtime snapshot trả revision/ETag; publish role mới được đọc lại qua
  `/internal/v1/runtime-config` mà không restart process trong test injection.

Các số trên là contract/fixture evidence, chưa phải physical speaker acceptance
hoặc warm TTFA/real ASR/TTS benchmark. Raw credential, Wi-Fi secret và transcript
thật tuyệt đối không ghi ở đây.

## Limitations / next gate

- Voice Server M0 fixture dùng ASR/LLM deterministic và tone TTS; provider
  PhoWhisper/VieNeu/Groq thật cần artifact/runtime được cài và benchmark.
- Firmware/board profile chưa được flash vì BOM/pin map exact chưa có; không bịa
  GPIO.
- PostgreSQL adapter và device pairing/MCP hardware thuộc gate tiếp theo; memory
  API hiện dùng host memory khi chạy `VEETEE_DATABASE_MODE=memory`.
