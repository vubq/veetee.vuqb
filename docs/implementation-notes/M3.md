# M3 implementation note

## UDP v3 framing/crypto/reorder core — host-only (2026-08-05)

Đã triển khai phần lõi carrier theo `docs/03-protocol-spec.md` mà không mở MQTT
broker, UDP socket, network route hay audio device. Module
`veetee-server/src/veetee_server/mqtt_udp.py` có ranh giới rõ:

- parse server hello `transport="udp"`, key/nonce 16-byte và optional audio
  parameters; key/nonce không được log;
- serialize/validate header UDP v3 16 byte (`type`, `flags`, `payload_len`,
  `ssrc`, `timestamp`, `sequence`) và AES-128/CTR dùng toàn bộ header làm IV;
- sequence bắt đầu từ `1`, chặn payload trên 1.400 byte và từ chối wrap trước
  khi reuse IV;
- bounded reorder window 4 packet, forward jump tối đa 256, gap timeout 120 ms,
  duplicate/late drop và reset state khi protocol error.

Golden vector dùng key/nonce giả lập được lưu tại
`tests/fixtures/mqtt_udp_v3.json`; không chứa credential thật, raw audio hay
secret. Test `veetee-server/tests/test_mqtt_udp.py` chỉ dùng payload byte nhỏ để
kiểm tra framing/crypto, không phát hoặc mở microphone/speaker.

Verification:

- `uv run pytest -q`: **91 passed** (82 regression hiện có + 9 UDP core);
- `uv run ruff check src tests`: pass;
- `uv run python -m compileall -q src`: pass.

Đây chưa phải M3 DoD. MQTT control client, UDP gateway/socket, stream barrier
`tts/start`/`tts/stop`, loss/reorder soak, firmware transport, hardware MCP,
assets/OTA và physical acceptance vẫn deferred. Không được promote MQTT/UDP làm
default; direct WebSocket v3 vẫn là product default.
