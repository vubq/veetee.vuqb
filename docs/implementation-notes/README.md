# Implementation notes

Mỗi milestone có một note evidence riêng. Note phải trả lời được:

- scope và config revision đã dùng;
- file thay đổi và quyết định/ADR liên quan;
- lệnh build/test/benchmark đã chạy cùng kết quả;
- log đã redact, checksum/model revision nếu có;
- kiểm tra host/serial và kiểm tra vật lý mà chủ dự án phải nghe, nhìn hoặc chạm;
- limitation, câu hỏi còn mở và rollback commit;
- remote commit đã push.

Phần trăm chỉ là thông tin phụ, không thay thế DoD và không gắn ngày hoàn thành.
Không ghi secret, Wi-Fi password, bearer token hoặc audio/transcript nhạy cảm vào
note.
