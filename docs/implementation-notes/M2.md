  revision mà không restart.

  restart; migration one-shot chạy trước API trong manifest PostgreSQL riêng.

## Chưa đạt M2 production gate

Secret store mã hóa, opaque session/CSRF đầy đủ, generated OpenAPI client, device
pairing và history chưa được promotion. Runtime `host-native-dev.json` vẫn dùng
memory fixture để không ảnh hưởng M0/M1; manifest PostgreSQL riêng đã có cho M2.
Không coi fixture memory là production persistence.
