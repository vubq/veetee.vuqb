# M1 implementation note

## Đã có trong slice hiện tại

- `DeviceMcpBridge` dùng JSON-RPC ID tăng dần, allow-list descriptor từ snapshot,
  timeout cấu hình và generation cancellation; unit suite server hiện **9 tests
  pass**.
- Pipeline nhận tool-call delta, assemble arguments, gọi MCP device và tiếp tục
  LLM theo giới hạn round trong config; không chọn provider khác khi lỗi.
- Realtime mode có server-side barge-in gate theo `bargeIn.minSpeechFrames`;
  button/local mute vẫn phải do firmware physical layer thực hiện.
- Turn cancellation đã có generation ownership guard: pipeline kiểm tra
  cancellation trước/sau mỗi TTS chunk và trước khi packetize; session xoá
  ownership trước khi await task cũ, đồng thời bỏ mọi control/audio frame mang
  `turn_id` cũ. Unit test `test_cancelled_turn_drops_queued_audio_packet` chứng
  minh packet không được phát sau barrier.
- Progress acknowledgement đã chạy theo snapshot (`deadlineMs`,
  `acknowledgementId`, `acknowledgements`); test fixture chứng minh ack được phát
  trước LLM answer chậm mà không chèn câu chữ trong code. PhoWhisper ingress dùng
  file-backed float32 spool thay vì giữ toàn bộ PCM chunks trong RAM.
- Registry đã có selection tùy chọn cho `veetee.intent.patterns` và
  `veetee.memory.session-window`: exit/cancel pattern phát event + abort có
  generation guard, còn memory giữ bounded JSON turn window theo từng WebSocket
  session. Cả rule/locale/action và giới hạn memory đều đi từ provider config.
- Host-native Web proxy map `/api`, `/openapi.json`, `/veetee` qua target được
  cấu hình; private Tailscale Serve đang proxy UI trên hostname tailnet.

## Chưa đạt M1 DoD

WakeNet/AEC thật, long-session soak, Groq/VieNeu warm TTFA dưới target và physical
MCP chưa được acceptance. Không dùng fixture tone/ASR để tuyên bố robot đã nói tự
nhiên.
